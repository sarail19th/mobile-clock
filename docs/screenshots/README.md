# Screenshots

Drop phone screenshots here (JPEG, metadata stripped with `convert -strip -quality 82`); the gallery in the top-level README picks them up.

| File | Status |
|---|---|
| `clock.jpg`, `alarms.jpg`, `timer.jpg`, `stopwatch.jpg`, `world.jpg` | done |
| `widget-editor-templates.jpg`, `widget-editor-lines.jpg` | done |
| `widget-home.jpg` | wanted: home screen with the widget placed; use a wallpaper you own or that is free to publish |
| `settings.jpg` | wanted: Settings list, or Permission health with everything green |

Tips: Samsung power + volume-down takes a screenshot; keep them portrait, around 1080 px wide, and run
`convert -strip -quality 82 in.jpg out.jpg` (or similar) so the repo stays small. Hide notifications, and use a wallpaper you are
happy to publish.
