# Screenshots

Drop phone screenshots here with these exact names; the table in the top-level README picks them up.

| File | What to capture |
|---|---|
| `widget-home.png` | Home screen with the widget placed (ideally 2x2 and 4x1) |
| `widget-editor.png` | Widget editor with live preview |
| `alarms.png` | Alarm list with the seed alarms and the "Next skip" line |
| `timer.png` | Timer tab with two timers running |
| `world.png` | World clock with a few cities |
| `settings.png` | Settings, Permission health (all green) |

Tips: Samsung power + volume-down takes a screenshot; keep them portrait, around 1080 px wide, and run
`pngquant --quality 70-90 *.png` (or similar) so the repo stays small. Hide notifications, and use a wallpaper you are
happy to publish.
